# বেটিং শিল্ড বিডি (Betting Shield BD)

বাংলাদেশে বেটিং ওয়েবসাইট ব্লক করার একটি বিনামূল্যের Android অ্যাপ। অ্যাপটি ফোনের ভেতরেই একটি লোকাল ডিএনএস ফিল্টার চালায় (কোনো ভিপিএন সার্ভার বা টাকা লাগে না)।

> **সীমাবদ্ধতা (সৎভাবে):** অ্যাপ শুধু তালিকায় থাকা ওয়েবসাইটের নাম ব্লক করে। অন্য ভিপিএন, প্রাইভেট ডিএনএস, ব্রাউজারের "Secure DNS", নতুন ডোমেইন বা আইপি ঠিকানা দিয়ে খোলা সাইট এটি এড়িয়ে যেতে পারে। বেটিং অ্যাপ শুধু শনাক্ত ও আনইনস্টলে সাহায্য করা যায়; চালু হওয়া আটকানো যায় না।

---

## ধাপ ১: GitHub-এ কোড আপলোড (ব্রাউজার থেকে, কোনো কমান্ড ছাড়া)

1. https://github.com এ অ্যাকাউন্ট খুলুন (ফ্রি)।
2. ডান পাশের উপরে **+ → New repository** চাপুন। নাম দিন `betting-shield-bd`। **Public** বেছে নিন (Public হলে বিল্ড ফ্রি ও APK ডাউনলোড সহজ)। **Create repository** চাপুন।
3. নতুন পেজে **uploading an existing file** লিংকে চাপুন।
4. কম্পিউটারে `BettingShieldBD.zip` ফাইলটি এক্সট্র্যাক্ট (Unzip) করুন। ভেতরের **সব ফাইল ও ফোল্ডার** (`.github` ফোল্ডারসহ) টেনে এনে GitHub পেজে ছাড়ুন।
   - যদি `.github` ফোল্ডার না আসে (লুকানো ফোল্ডার), ফাইল ম্যানেজারে "Show hidden files" চালু করুন।
5. নিচে **Commit changes** চাপুন।

## ধাপ ২: APK তৈরি হওয়া দেখা

1. রিপোজিটরির উপরের **Actions** ট্যাবে যান। প্রথমবার "I understand my workflows, go ahead and enable them" চাইলে চাপুন।
2. **Build APK** নামের কাজটি চলবে (৫–১০ মিনিট)। সবুজ ✔ হলে শেষ।
   - লাল ✖ হলে সেই লাইনে ক্লিক করে লগের শেষ ২০ লাইন কপি করে আমাকে পাঠান; আমি ঠিক করে দেব।
3. রিপোজিটরির মূল পেজের ডান পাশে **Releases → Latest APK** এ ক্লিক করুন। সেখান থেকে **BettingShieldBD.apk** ফোনে ডাউনলোড করুন।

## ধাপ ৩: ফোনে ইনস্টল (Vivo, Android 15)

1. ডাউনলোড করা `BettingShieldBD.apk` ফাইলে চাপুন।
2. "Install unknown apps" চাইলে ব্রাউজারের জন্য অনুমতি দিন, তারপর **Install**।
3. যদি Vivo/Google Play Protect সতর্ক করে, **Install anyway / More details → Install anyway** চাপুন (অ্যাপটি Play Store-এ নেই বলে এই সতর্কতা আসে)।
4. অ্যাপ খুলে **চালু করুন** চাপুন এবং ভিপিএন অনুমতিতে **OK** দিন।
5. Vivo-তে চালু রাখতে: অ্যাপের ভেতরের **সেটিংস ও সাহায্য** স্ক্রিনের ব্যাটারি ধাপগুলো অনুসরণ করুন, এবং **Always-on VPN** চালু করুন।

## ধাপ ৪: ব্লকলিস্ট আপডেট চালু করা (একবারের কাজ)

অ্যাপ নিজে নিজে আপনার রিপোজিটরির `blocklist/` ফোল্ডার থেকে তালিকা নামায়। তালিকা নিরাপদ রাখতে ডিজিটাল সিগনেচার ব্যবহার হয়।

1. রিপোজিটরিতে **Settings → Secrets and variables → Actions → New repository secret** এ যান।
2. নাম দিন `BS_PRIVATE_KEY`, মান হিসেবে আমার দেওয়া `private.key` ফাইলের লেখাটি পুরোটা পেস্ট করুন। **এই ফাইল কাউকে দেবেন না, GitHub-এর পাবলিক ফাইলেও রাখবেন না।**
3. (ঐচ্ছিক, কিন্তু ভবিষ্যতে অ্যাপ আপডেটের জন্য ভালো) আরও দুটি secret: `KEYSTORE_BASE64` ও `KEYSTORE_PASSWORD` — আমার দেওয়া `keystore-secrets.txt` ফাইলে আছে।

এরপর নতুন সাইট যোগ করতে: `blocklist/manual.txt` ফাইলটি GitHub ওয়েবে খুলে ✏️ (Edit) চেপে নতুন লাইনে ডোমেইন লিখে Commit করুন। কয়েক মিনিটে workflow তালিকা যাচাই, সাইন ও প্রকাশ করবে; ফোনের অ্যাপ পরের আপডেটে (১২ ঘণ্টা বা "এখনই হালনাগাদ") নতুন তালিকা নেবে।

ভুল করে ব্লক হওয়া সাইট ঠিক করতে: ডোমেইনটি `blocklist/allow.txt` এ লিখুন।

প্রতি সোমবার workflow পাবলিক জুয়া-ব্লকলিস্ট (`blocklist/sources.txt`) থেকে নতুন ডোমেইন যোগ করে। চাইলে **Actions → Update signed blocklist → Run workflow** চেপে এখনই চালাতে পারেন।

## ধাপ ৫: রিপোর্ট সিস্টেম চালু (Cloudflare, ফ্রি)

অ্যাপের "বেটিং ওয়েবসাইট রিপোর্ট করুন" কাজ করতে একটি ছোট সার্ভিস লাগে। `worker/README.md` এ ধাপগুলো আছে। শেষে সার্ভিসের ঠিকানাটি GitHub রিপোজিটরির **Settings → Secrets and variables → Actions → Variables → New repository variable** এ `REPORT_ENDPOINT` নামে রেখে **Build APK** আবার চালান।

## প্রজেক্টের ফোল্ডার

| ফোল্ডার | কী আছে |
|---|---|
| `app/` | Android অ্যাপের কোড |
| `blocklist/` | ব্লকলিস্ট, বেটিং অ্যাপের তালিকা, সিগনেচার |
| `worker/` | রিপোর্ট সার্ভিসের কোড (Cloudflare) |
| `tools/` | তালিকা বানানো ও সাইন করার টুল |
| `.github/workflows/` | স্বয়ংক্রিয় APK বিল্ড ও তালিকা হালনাগাদ |

## পরীক্ষা (Acceptance) চেকলিস্ট

ফোনে ইনস্টলের পর এগুলো যাচাই করুন:

- [ ] অ্যাপ চালু হয়, "সুরক্ষা চালু আছে" দেখায়।
- [ ] ব্রাউজারে `bet365.com` খুললে খোলে না।
- [ ] Google, YouTube, Facebook, ব্যাংকিং অ্যাপ স্বাভাবিক চলে।
- [ ] ফোন রিস্টার্টের পর সুরক্ষা আবার চালু হয় (না হলে ব্যাটারি/Autostart ধাপ দেখুন)।
- [ ] অন্য ভিপিএন চালালে অ্যাপ "সুরক্ষা বন্ধ" নোটিফিকেশন দেয়।
- [ ] "এখনই হালনাগাদ" চাপলে সফল বা পরিষ্কার ত্রুটির বার্তা দেখায়; ব্যর্থ হলে আগের তালিকাই চলে।
- [ ] রিপোর্ট পাঠানো ও স্ট্যাটাস দেখা যায় (রিপোর্ট সার্ভিস চালুর পর)।

## গোপনীয়তা

ওয়েবসাইটের নাম ফোনের ভেতরেই যাচাই হয়, আপলোড হয় না। রিপোর্টে শুধু ওয়েবসাইটের ঠিকানা, ঐচ্ছিক নোট ও এলোমেলো রিপোর্ট নম্বর যায়। কারও ফোনে তাঁর জ্ঞাত ও সম্মতি ছাড়া এই অ্যাপ ইনস্টল করবেন না।
